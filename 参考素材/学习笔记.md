# 麻将江湖 UI 调研学习笔记

> 调研日期：2026-08-26 · 范围：生存 Roguelike HUD / 麻将牌桌 / 中式国风 UI

## 一、同类生存 Roguelike 的 HUD 布局

### Vampire Survivors
- **顶部横贯全屏的经验条**是最强识别元素——升级进度是本类游戏第一关注点。
- 金币计数、计时器放顶部两角；武器/被动图标列在**左上角竖排**（带等级角标）。
- 升级面板：暂停游戏 → 3~4 个选项（第4个受幸运属性影响）→ **已拥有物品优先出现**（有公式权重）→ 选择后短暂无敌再恢复战斗。
- 无可升时降级为回血/金币选项；Reroll/Skip/Banish 作为成长项挂在面板上。
- 设计哲学：less is more —— HUD 极简，把视觉留给弹幕与掉落洪流。

### HoloCure
- **左上角集群**：角色头像 + HP 条 + 数值 + 特殊攻击充能条，聚成"玩家状态块"。0.5 版特意缩小头像省视野，且**受伤时头像震动**提供反馈。
- 武器 6 格 + 道具 6 格图标紧贴头像下方，一眼看清 build 成型度。
- 右上角：关卡名 + 计时器；金币 + 击杀数同侧成组。
- Buff 图标统一排在**屏幕底部中央**。
- 启示：同类信息必须聚类成"块"，不要散落四角。

### Brotato
- 反编译源码证实：life_bar / xp_bar / gold 三控件独立挂载、按 hud_visible 统一开关 —— HUD 元素组件化管理。

### 共性规律
1. 经验条=顶部通栏；生命=左上；货币/计时=右上；buff=底部。
2. 角落信息靠描边/投影/半透明底板保证任意背景可读。
3. 关键数值用等宽数字 tabular-nums 防跳动。
4. HUD 只放"高频+紧急"的信息，其余进菜单。

## 二、升级三选一面板的优秀做法
- 冻结世界：面板弹出即暂停（本项目已有 `.game-clock-frozen`，正确）。
- 卡片信息层级：图标 > 名称 > 当前等级→下一等级变化描述（VS 后期补上升级前后对比）。
- 已拥有装备标 LV n→n+1、新装备标 NEW 徽章；可预告进化路线（VS evo indicator）。
- 数字键 1/2/3 快捷选择 + 悬停高亮；Reroll/跳过作为次要按钮弱化显示。
- 选择完成后给约 1s 无敌缓冲，避免恢复瞬间被围殴的挫败感。

## 三、麻将手牌 UI 排列与听牌提示惯例（雀魂/天凤）
- 手牌横排**屏幕底部居中**，牌面朝向玩家略带透视；摸牌与手牌间留明显缝隙（约一张牌宽的 15%~20%）。
- 自动理牌为默认：万/筒/条/字分组、组内升序；天凤保留手动理牌开关。
- 操作按钮（吃碰杠胡过）出现在**手牌正上方**，仅可鸣牌时点亮；不可用时灰显而非隐藏。
- 听牌提示：立直/听牌状态给文字徽标；振听明确警示"不能荣和"；雀魂官方每周"何切"题证明"提示打哪张"是高频需求。
- 和牌演出（役种展示+特效）是情绪峰值点，值得投入美术资源。

## 四、中式/国风游戏 UI 案例
1. **即时设计《国风 UI 攻略》**：① 祥云/回纹/灯笼/梅花符号化进图标与按钮；② 用传统中国色（朱红、青花蓝、鎏金、墨绿）分层配色；③ 水墨背景大面积留白；④ **对称排版**传达庄重感，再叠加现代网格的灵活性。
2. **雀魂**：和风二次元外壳包硬核规则——3D 牌桌昼夜光影、和牌专属演出、表情互动。启示：主题皮肤化（牌桌/牌面/精灵可换装）是长线运营抓手。
3. **Kenney Fantasy UI Borders / UI Pack**（CC0）：石质/金属描边框证明"边框即风格"——仅替换面板边框九宫格即可整体换皮，适合本项目 CSS border-image 或 box-shadow 方案。

## 五、对本项目的 8 条可执行改进建议
1. **HUD 分区对齐惯例**：经验条移至顶部通栏；HP/护甲聚左上角成块；金币/波次/计时归右上角——当前若散落多处，按 VS/HoloCure 惯例重组。
2. **Overdrive 怒气槽贴底居中**（HoloCure buff 位）：满槽时脉动动画 + "SPACE" 键提示浮现；充能时数字用 tabular-nums。
3. **升级三选一卡片**：每张卡显示 LV n→n+1 与属性增量对比行，新装备加 NEW 角标；支持键盘 1/2/3 选择；选完给 0.8~1s 无敌。
4. **胡牌系统手牌区**：手牌底部居中横排，摸牌与手牌间留缝；万/筒/条/字自动分组排序；听牌时高亮可胡张（雀魂式发光），振听状态加红色警示徽标。
5. **鸣牌/操作条**：吃碰杠胡按钮放手牌正上方一行，不可用时灰显不隐藏——为胡牌系统预留交互位。
6. **国风化面板**：奖励/事件面板边框改鎏金描边 + 四角回纹装饰（参考素材纹样目录 SVG 可内联为 CSS mask）；背景半透明墨色 + 宣纸噪点。
7. **受伤反馈**：左上头像震动 150ms + 屏幕边缘红晕 vignette（meta UI），替代纯掉血数字。
8. **牌桌材质**：绿色呢绒垫（oga_green_mat_tablecloth.png）做世界层底纹，木纹（ambientcg planks）做边框区，大理石（marble014）留作结算面板底——全部可用 CSS 渐变近似实现，保持零图片铁律。
