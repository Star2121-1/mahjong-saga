## 二、各参考设计分析

### 参考 1：Vampire Survivors 主菜单

**URL**: https://www.vampire-survivors.com/ (官方), Steam Store

**核心设计特点**:
- 极简布局：中央大标题 + 几个简洁按钮（Continue / New Game / Options）
- 深色森林背景，低饱和度暗绿色调 (#1a2f1a 近似)
- 按钮使用粗体白色文字 + 微光边框，无复杂装饰
- 右上角显示金币/时间等元数据
- 整体气质：复古、简洁、沉浸式

**可直接借鉴**:
- 按钮层级：主要操作（开始游戏）视觉上压倒一切
- 顶部状态栏布局（资源计数放在右上角）
- 暗色背景的"沉浸感"优于亮色背景

### 参考 2：HoloCure 大本营

**URL**: https://holocure.fandom.com/, YouTube 演示视频

**核心设计特点**:
- 中心角色立绘 + 四周功能按钮（角色选择/商店/设置等）
- 明亮的粉色/紫色赛璐璐风格（与本项目绿金完全不同）
- 底部一排图标式导航（类似工具栏）
- 顶部玩家等级/金钱显示

**可直接借鉴**:
- 角色立绘作为视觉中心（主角 portrait 在左上或中央）
- 按钮网格化排列，图标 + 文字并排
- 鲜明的视觉分区（角色区 / 功能按钮区 / 资源区）

### 参考 3：雀魂 (Mahjong Soul) 大厅

**来源**: B站 视频 BV1TT4y127VY，官方客户端

**核心设计特点**:
- 日式轻小说风格，大量美少女立绘
- 主色调：粉白 + 金色，清新明亮
- 左侧导航栏（段位/房间/设置等）
- 中央大场景 + 立绘
- 顶部货币显示（JC/PT）

**可直接借鉴**:
- 麻将主题游戏的布局范式（大厅 → 房间 → 对局）
- 角色立绘占据视觉中心
- 顶部状态栏 + 左侧功能导航的经典布局

### 参考 4：中国风游戏 UI（通用参考）

**来源**: 花瓣网 / 各类国风手游 UI 概念图

**核心设计特点**:
- 深墨绿 + 鎏金 + 象牙白三色体系
- 竹简/卷轴纹理作为导航容器
- 毛笔字体（楷体/隶书）标题
- 红纸/封条作为强调元素
- 窗棂/回纹边框装饰

**可直接借鉴**:
- 本项目已有的绿金配色方向是对的
- 竹节纹理导航栏可以进一步强化
- 红色强调色只用于最重要操作（出征按钮）——本项目已做

### 参考 5： roguelike 大本营布局（通用模式）

**来源**: Balatro, Dead Cells, Slay the Spire 等

**核心设计特点**:
- 卡片式功能模块（每个系统一张卡片）
- 进度可视化（深渊层数/通关次数用大数字展示）
- 左侧垂直导航 + 右侧内容区是主流布局
- 底部有时放一行快捷操作

**可直接借鉴**:
- 当前项目的「左侧导航 + 右侧画布」已经是正确方向
- 可以考虑把 9 个 tab 按功能分组（战斗/养成/数据）
- 大数字 + 短标签的统计展示方式

## 三、推荐设计方向（5-8个）

### 方向 A：竹林禅意 · 极简沉浸

**布局**: 全屏深色竹林背景 + 居中标题Logo + 底部一排大按钮  
**配色**: `#0a1d12` 底色 / `#1a5336` 竹绿 / `#ffd700` 鎏金 / `#fbfbf7` 象牙白  
**特点**: 
- 去掉左侧导航栏，改为底部横向按钮（类似 HoloCure）
- 顶部状态栏保留但更精简
- 英雄立绘作为全屏背景（可淡入淡出切换4英雄）
- 适合16:9宽屏，强调沉浸感
**借鉴**: Vampire Survivors 的极简主义 + HoloCure 的居中布局

### 方向 B：卷轴竹简 · 传统叙事

**布局**: 左侧竹简卷轴导航 + 右侧展开的"画卷"内容区  
**配色**: 当前绿金体系不变，增强竹节纹理  
**特点**:
- 保留现有左侧导航，但改为竹简造型（圆角 + 竹节分割线）
- 内容区用宣纸质感背景（#f5eedc 象牙色，而非纯黑）
- 标题用毛笔书法体放大（楷体/隶书）
- 每个面板有"折页"过渡动画
**借鉴**: 雀魂大厅的传统日式布局 + 中国古典卷轴美学
**最推荐**: 与现有代码改动最小，视觉提升最大

### 方向 C：牌桌江湖 · 麻将主题

**布局**: 中央麻将牌桌作为视觉核心，功能按钮以"牌"的形式排列  
**配色**: 深绿牌桌布 (#133b26) + 象牙白麻将牌 (#f5f0e8) + 鎏金文字  
**特点**:
- 9个功能用9张麻将牌表示（万/筒/索 + 风箭）
- 点击"牌"翻转进入对应面板
- 中央展示当前英雄的麻将牌肖像
- 顶部状态用"筹码"形式（金币/核心用筹码图标）
**借鉴**: 麻将主题的独特差异化 + Vampire Survivors 的按钮层级
**最大亮点**: 与游戏主题高度一致，独一无二

### 方向 D：赛博竹阵 · 现代混搭

**布局**: 左侧霓虹灯管式导航 + 右侧网格化内容卡片  
**配色**: 深黑 (#0d0d0d) + 霓虹绿 (#39ff14) + 金色 (#ffd700) + 品红强调 (#ff006e)  
**特点**:
- 赛博朋克风格的发光边框和文字
- 霓虹灯管效果导航项
- 内容卡片用 glassmorphism（毛玻璃）
**借鉴**: 现代独立游戏 UI 趋势
**风险**: 与现有东方武侠氛围不协调，暂不推荐

### 方向 E：江湖客栈 · 场景化

**布局**: 中央客栈场景（CSS绘制），NPC按钮散布在场景中  
**配色**: 暖黄灯光 (#ffb347) + 深木色 (#3e2723) + 朱砂红 (#b62929)  
**特点**:
- 用CSS box-shadow 绘制客栈场景（类似麻将牌的 CSS 技巧）
- 功能区域对应客栈不同角落（招募=吧台，锻造=后院，图鉴=书房）
- 英雄立绘作为"掌柜"站在中央
**借鉴**: 日式RPG Town hub 概念
**优点**: 故事感强，适合麻将江湖的武侠设定

### 方向 F：极简暗调 · 功能优先

**布局**: 顶部状态栏 + 左侧小导航 + 右侧大内容区（类似当前但更紧凑）  
**配色**: 当前绿金微调，提高对比度  
**特点**:
- 保持当前左右分栏结构
- 缩小左侧导航宽度（20%→15%）
- 增大内容区空间
- 提高文字对比度（#8aab9a → #b0d0c0）
- 按钮更方硬，减少圆角
**借鉴**: Balatro 的极简风格 + 现有代码最小改动
**最稳妥**: 低风险快速提升

## 四、最终推荐方案

### 推荐：方向 B（卷轴竹简）+ 方向 C（牌桌江湖）混合

**理由**:
1. 与现有代码架构兼容（保留左侧导航 + 右侧画布）
2. 麻将主题最大化（用麻将牌作为功能入口）
3. 中国风美学延续（竹简、楷体、绿金配色）
4. 改动量适中，不需要重写整体布局

### 具体 CSS 色值建议

```css
/* ── 大本营主题色修订版 ── */
:root {
    /* 背景层级 */

    --hub-bg-main: #0d1a12;       /* 主体深绿（保持不变）*/
    --hub-bg-panel: rgba(13,26,18,0.85); /* 面板背景 */
    --hub-bg-paper: #f5eedc;      /* 宣纸色（新：内容区可用） */
    
    /* 绿色层级 */
    --hub-green-deep: #0a1d12;    /* 深处墨绿 */
    --hub-green: #133b26;         /* 雀坛绿（不变） */
    --hub-green-mid: #1e6f42;     /* 竹翠（不变） */
    --hub-green-light: #2d9254;   /* 新：亮绿（hover/高亮） */
    --hub-green-border: #1a5336;  /* 边框绿（不变） */
    
    /* 金色层级 */
    --hub-gold: #d4af37;          /* 鎏金（不变） */
    --hub-gold-bright: #ffd700;   /* 亮金（不变） */
    --hub-gold-dim: rgba(212,175,55,0.4); /* 金色半透明 */
    
    /* 红色强调（出征/精英） */
    --hub-red: #b62929;           /* 宫墙朱砂（不变） */
    --hub-red-bright: #ff5252;    /* 亮红（hover） */
    
    /* 文字层级 */
    --hub-text-primary: #fbfbf7;  /* 象牙白（不变） */
    --hub-text-secondary: #a8c8b8;/* 次级绿白（不变） */
    --hub-text-muted: #6a8a7a;    /* 弱绿（原 #7a9a8a，微调） */
    --hub-text-dim: #4a6a5a;      /* 新：极弱文字 */
    
    /* 蓝色辅助（信息/数据） */
    --hub-blue: #4fc3f7;          /* 琉璃蓝（不变） */
    --hub-blue-dim: rgba(79,195,247,0.15);
    
    /* 新：宣纸暖白（面板卡片可用） */
    --hub-ivory: #f5f0e8;
    --hub-ivory-dark: #e8dfd0;
}
```

### 布局调整建议

```css
/* ── 关键布局改动 ── */

/* 1. 左侧导航加宽 + 增强竹简质感 */
#hub-left-nav {
    width: 22%;               /* 原 20% → 22%，给导航更多呼吸空间 */
    background: linear-gradient(180deg, #070e09 0%, #0d1a12 30%, #0a1a0f 70%, #070e09 100%);
    border-right: 2px solid #1a5336;
    /* 增强竹节纹理 */
}

/* 2. 导航项改为「竹简牌」造型 */
.nav-item {
    border-radius: 4px 12px 12px 4px;  /* 左圆右方，模拟竹简 */
    border-left: 3px solid transparent; /* 左侧加重，像竹简装订 */
    padding: 14px 12px;
}
.nav-item.active {
    border-left-color: #d4af37;  /* 激活态左侧金色边 */
}

/* 3. 出征按钮（血战到底）改为「红色封条」造型 */
.nav-item[data-panel="expedition"] {
    border-radius: 4px;
    border: 2px solid #b62929;
    background: rgba(182,41,41,0.12);
    /* 像一张红色的出征令 */
}

/* 4. 右侧内容区改用宣纸色卡片 */
.hub-panel { 
    /* 保持 flex-column，内容用 paper 色卡片 */
}

/* 5. 顶部状态栏更精致 */
#hub-top-stats {
    background: linear-gradient(180deg, rgba(7,14,9,0.95), rgba(7,14,9,0.75));
    border: 1px solid rgba(212,175,55,0.25);
    border-radius: 8px;
    /* 降低模糊，保持清晰 */
}
```
